### 🚀 Project Spotlights

- [**3D Perception Pipeline**](https://github.com/adityashah1603/3D-perception-pipeline)  
  LiDAR + camera sensor fusion for ADAS and robotics, with 3D object detection (CenterPoint) and multi-object tracking (ByteTrack) on the nuScenes benchmark.

- [**CaseLens**](https://github.com/adityashah1603/CaseLens)  
  A deployed AI copilot for searching and reasoning over case evidence.

- [**AdvertiseAI: Agentic Ad Generation & Deployment**](https://github.com/adityashah1603/AdvertiseAI)  
  Multi-agent pipeline that takes a brand spec and a request, generates an on-brand ad, lets a human iterate via pinned comments, then has a second agent deploy the final ad to an ad platform using a real browser. Every agent task runs in an ephemeral sandbox hydrated from Supabase storage, so no state lives only inside a box.

- [**Action Tokenization for VLA Models in Autonomous Driving**](https://github.com/adityashah1603/VLA-Autonomous-Driving)  
  Master's project comparing 7 action tokenization methods for a Vision-Language-Action driving model (SigLIP ViT-B/16 + SmolLM2-360M with LoRA) in CARLA. Found that DCT compression, which works well in robotic manipulation, gives ~14× higher error for driving because brake/throttle signals are step-like.

- 📄 [**AI-Enhanced Human-Machine Interface for Power Wheelchair Navigation: Effects of Communication Strategy and Vibrotactile Feedback Location**](https://journals.sagepub.com/doi/10.1177/10711813261493634)  
  Co-authored research at [**BATLab, SJSU**](https://batlab.info/), published at HFES ASPIRE 2026. A pilot study on how an AI-enabled power wheelchair should communicate obstacle alerts, comparing action-focused vs. why-focused verbal cues and seatback vs. wrist vibrotactile feedback. Seatback vibrations led to higher user satisfaction.

- 📄 [**Exploring the Benefits of Data Augmentation for Breast Cancer Classification using Transfer Learning**](https://link.springer.com/chapter/10.1007/978-981-99-8612-5_41)  
  Co-authored at Nirma University, published by Springer (ISBM 2023, Smart Innovation, Systems and Technologies vol. 379). Designed a data augmentation algorithm to address the scarcity of quality mammogram images, then compared DenseNet, ResNet, and EfficientNet transfer-learning models as a second-opinion tool for radiologists.

- [**Hate Speech & Cyberbullying Detection in Tweets**](https://github.com/adityashah1603/Detecting-and-Classifying-Hate-Speech-in-online-tweets)  
  Trained and compared SVM, XGBoost, and fine-tuned RoBERTa classifiers on 47K+ tweets, then served the best model (exported to ONNX) through a Flask + React web app.
